# B-0001: Add greet function

## Scope
Implement a `greet` function in this TypeScript project.

## Required changes
1. Create `src/greet.ts`:
   - Export a named function `greet(name: string): string`.
   - It must return the literal `` `Hello, ${name}!` `` (template string), so `greet("world")` returns `Hello, world!` and `greet("")` returns `Hello, !`.
2. Update `src/index.ts`:
   - Re-export `greet` from `./greet.js` (NodeNext ESM resolution requires the `.js` suffix on the import specifier even though the source file is `.ts`).
   - You MAY keep or remove the existing `placeholder` export; tests do not depend on it.
